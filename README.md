# RDR2 Native DB
index.php, combines with the .sql file provided inside a MySQL database using your db credentials to connect and fetch native information

# List Converter
converter.php, allows you to paste or provide a URL for a list in any supported format and outputs it to another format (C++ -> LUA or TXT -> JSON)

# Script Generator
creator.php, aides in creating scripts for YimMenuV2/Helix/HorseMenu/Chronix to add new features such as Godmode (LoopedCommand) or Suicide (Command)
